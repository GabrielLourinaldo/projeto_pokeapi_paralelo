Instalar dependências e rodar o projeto:

1. Instalar Python 3.8+.
2. Criar e ativar um ambiente virtual opcional.
3. Executar:
   ```bash
   pip install -r requirements.txt
   ```
4. Rodar scripts em `src/` (todos em sequência e observar os resultados), por exemplo:
   ```bash
   python src/sequencial.py
   ```

Dependências necessárias:
- requests
- pandas
- openpyxl
